# TRAIN LIKE A PRO

## הפעלה מקומית

1. פתח Terminal בתיקיית הפרויקט.
2. הרץ:
   npm install
3. לאחר מכן:
   npm start
4. פתח בדפדפן:
   http://localhost:3000

## שמירת הטפסים

הטפסים נשמרים **מחוץ** לתיקיית הפרויקט, בתיקייה מקבילה:

    ../train-like-a-pro-data/applications.json

זה מכוון: כך הקובץ לעולם לא נגיש דרך האתר (בעבר הוא היה בתוך הפרויקט,
וחשוף בטעות תחת express.static). אל תעביר את הקובץ בחזרה לתוך תיקיית
הפרויקט.

לפני כל שמירה נוצר גיבוי אוטומטי בתיקייה:

    ../train-like-a-pro-data/backups/

נשמרים 30 הגיבויים האחרונים בלבד (הישנים יותר נמחקים אוטומטית).

## עדכון סטטוס הגשה (למנהל בלבד)

יש endpoint לעדכון סטטוס הגשה בלי לגעת ישירות בקובץ:

    PATCH /api/applications/:id/status
    Header:  x-admin-token: <הטוקן שלך>
    Body:    { "status": "נקבעה שיחה" }

סטטוסים אפשריים: `חדש`, `בבדיקה`, `נקבעה שיחה`, `התקבל`, `נדחה`.

כדי להפעיל את זה יש להגדיר משתנה סביבה `ADMIN_TOKEN` לפני ההרצה, למשל:

    ADMIN_TOKEN=בחר-כאן-סיסמה-ארוכה-וייחודית npm start

בלי `ADMIN_TOKEN` מוגדר, ה-endpoint חסום לגמרי (503).

## חשוב

אין לפתוח את האתר רק עם Live Server כאשר רוצים לשמור טפסים,
משום ש-Live Server אינו מפעיל את ה-API.
